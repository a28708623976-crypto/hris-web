# 员工接口与共享校验阶段

构建、原有 `npm test`、15 组后端测试通过。Wrangler 已在本地应用迁移并实际重置写入 12 名测试员工、3 个从忽略环境文件读取的测试账号；没有远程命令。

提供 GET 列表/详情、POST、PUT，支持部门/状态/入职年月/关键词。工号由 D1 序列分配，忽略客户端工号；创建支持 Idempotency-Key 防重复提交，更新使用返回的 version 防覆盖并发修改。

`shared/employees.ts` 为前后端唯一 Zod 校验，`shared/dates.ts` 为同一套原型日期/年龄/工龄计算，原有 23 个校验对照继续通过。新增字段错误响应、非负金额和有效日历日期校验。种子只补原型空缺的必填测试项，不将真实邮箱写入代码；原型附件文件名不当成真实 R2 文件。

直接查询测试 D1 验证：银行卡、证件、薪资字段不在 public_json 中，敏感组全部 AES-GCM 密文；读取本人薪资成功，读取他人/部门负责人拒绝且响应没有薪资字段。读写审计包含 actor/employee/动作/时间/字段名，无敏感值。测试覆盖全部筛选、必填和格式错误、并发工号、幂等创建、version 冲突、客户端伪造附件字段被忽略。

最终核对补充：后端重新计算只读试用期结束日；入职日改变但合同到期日仍为旧值时，按原型三年规则重新生成，显式手改/续签日期继续保留。新增直接伪造派生日期的 API 回归，防止仅依赖前端计算。
