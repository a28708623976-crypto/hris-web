# 验收记录

- `npm run build`：TypeScript 检查与 Vite 生产构建通过。
- `npm test`：6 项断言测试通过，覆盖薪资路由权限、员工与部门数据隔离、简化薪资汇总和绩效划线边界。
- `npm run check:routes`：110 组路由 / 角色组合通过服务端渲染检查，同时检查空值、个人考勤和部门人员范围。
- 在现有 Chrome 实际验证：首页渲染、员工姓名搜索（12 条缩小至张伟 1 条）、卡片切换、切换员工身份、直接访问薪资地址跳转 403，以及恢复 HR 主管身份。

自动化 Chrome 子进程在此运行环境被系统终止，浏览器连接器也不可用。因此未宣称全流程浏览器自动化、移动端真实视口验收或 PDF 打印成品验收。`qa/browser-smoke.mjs` 保留为可在正常 Chrome 环境运行的自动化脚本，需要先启动开发服务；它检查所有主要路由并生成桌面 / 手机视口截图。

本记录仅针对本地 Mock 前端；不包含真实业务系统、飞书集成、薪资合法性或服务端权限验收。
