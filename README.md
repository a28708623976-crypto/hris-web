# 屿生代 HRIS 前端

依据《HRIS Web App 前端 Spec.md》实现的 React 18 + TypeScript + Tailwind CSS v3 本地演示。

## 运行

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm run build
npm test
npm run check:routes
```

## 已实现

- 首页：人员指标、团队趋势示意、部门分布、待办与快捷入口。
- 员工：搜索筛选、卡片/表格、详情六个页签、新建与编辑。
- 入转调离：四列看板、六类流程、草稿、审批详情与模拟同意/拒绝。
- 合同：到期计算、警示、筛选、抽屉、续签入口与 CSV。
- 考勤薪资：月报、月历、核算、只读管理层视图、发放确认与历史记录。
- 证明：四类模板、实时预览、可编辑正文、样章、打印 PDF、最近生成历史。
- 员工自助：本人档案、申请提交/详情/撤回及证明申请。
- 招聘：职位编辑与状态、候选人评分/阶段/备注、安排面试与状态。
- 绩效：周期设置、权重校验、按身份和阶段录入、锁定、结果分布、校准与 CSV。

## 演示边界

所有姓名、联系方式和业务数据均为虚构。数据源在 `src/mock/`；浏览器 localStorage 键 `isleon-hris-demo-v1` 保存更改。清除此键并刷新可恢复初始数据。2026-11 为考勤薪资数据月份，其他月份显示空状态。

顶部切换五个角色。员工身份为 EMP001，部门负责人为 EMP004，HR / HR 主管 / 管理层使用 EMP005 演示身份。员工只见本人，部门负责人只见本部门；薪资页面与字段限 HR 主管/管理层，管理层只读。

**前端权限仅用于演示**：Mock 数据包含在静态包中，localStorage 可在开发者工具修改。正式接入前必须由服务端实现认证、数据级授权和薪资隔离，不能把此演示作为真实权限系统。

无真实登录、API、文件上传、审批通知、Offer 发送、电子签署或支付；证明公章是无效样章。流程审批改变流程状态；不会自动更新人员档案。`useFetch` 为未来 API 接入保留。招聘统计含示例累计数；趋势图和考勤日历为明确标注的示意数据。

薪资与个税是简化估算。PDF 使用浏览器打印，请选择“另存为 PDF”；没有预置真实合同附件或公司证照。

验收结果与未执行范围见 [qa/VERIFICATION.md](qa/VERIFICATION.md)。需要 Node.js 22.18+ 或 24+（测试使用原生 TypeScript 类型擦除）。
