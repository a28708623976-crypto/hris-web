# 权限与加密阶段

后端中间件强制角色及工号范围：HR 全部可读写；普通员工仅 GET 本人或受本人范围限制的列表；部门负责人全部拒绝。未登录由会话中间件先返回 401，拒绝响应仅含错误信息，不含敏感字段。

AES-256-GCM 每次使用随机 96 位 IV，并以员工号和字段组作为认证附加数据，防止密文跨员工或列替换。密钥要求 base64 编码的 32 字节值，来自 Worker 绑定。审计迁移记录操作者、目标员工、动作、敏感字段名称和时间，不记录字段值。

构建及 9 组本地测试通过，新增权限矩阵 27 个请求组合和随机密文、错误密钥、字段/工号交换、篡改拒绝检查。登录 7 组同时回归通过。实际员工表的密文和读写审计将在员工接口阶段直接查 D1 验证。
