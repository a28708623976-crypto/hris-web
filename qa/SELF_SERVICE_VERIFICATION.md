# 员工自助多级申请验收

日期：2026-11-26。本次仅员工自助的发起申请及申请类型路径为用户明确授权的原型例外。原型文件未修改；其他页面继续完整对照原型。

## 配置与实现

- `src/constants/selfService.ts`：四大类、每类两个业务分组，共 16 个末级事项。节点可以继续添加任意深度的 `children`；只有末级节点定义 `fields`。
- 字段配置包含 `name`、`label`、`type`、`required`，另可配置选项、最小值、步长、文件类型提示、多文件选择及关联日期字段。
- 字段类型：单行文本、多行文本、数字、日期、下拉选择、文件。
- `MultiLevelCascader`：逐层悬停或点击展开，末级才提交选择，输入框显示完整标签路径。支持方向键、Enter、Escape、外部点击关闭；深层菜单横向滚动，无固定层数。
- `RequestFields` 根据当前末级配置渲染表单。切换事项清空旧值和校验信息；提交成功清空字段及文件输入框。
- `src/store/selfService.ts` 提交时再次解析合法末级并校验，只保存当前配置字段，申请记录显示完整类型路径及填写摘要。历史三条样例记录同步为配置中的完整路径。

| 大类     | 配置示例                                                   | 主要字段                                                                  |
| -------- | ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 假勤申请 | 休假申请 → 年假/病假；加班与调休 → 调休/加班               | 起止日期、天数/小时、交接人、事由；不同事项有不同字段                     |
| 资产申领 | 电脑与外设 → 电脑/显示器；软件与账号 → 软件许可/AI 账号    | 型号/配置、数量、领用日期、用途；AI 账号另需月预算                        |
| 费用报销 | 差旅费用 → 差旅报销/出差补贴；日常费用 → 办公采购/业务招待 | 金额、发票、费用归属、发生日期、用途等；出差补贴按独立字段配置            |
| 综合行政 | 用印管理 → 公章/合同用印；个人行政 → 门禁/名片             | 用印文件、用途、份数、日期、经办人；合同另需相对方；门禁/名片使用各自字段 |

## 已通过的专项检查

`npm test` 新增 85 项员工自助检查：

- 四根分类、每类至少两个子级、16 个末级字段配置完整且字段名不重复。
- 所有末级路径可解析；中间层、错分支及不存在的路径不能提交；64 层路径无固定深度限制。
- 每个末级的必填字段为空时均阻止提交；空白文本、无效日期、日期倒序、无效数字/步长和非法下拉值均被拦截。
- 16 个事项都能按自己的字段成功提交，记录保留完整路径；非当前配置字段不入库；附件列表与输入数据隔离；申请 ID 唯一。

`npm run check:self-service` 通过 8 组浏览器场景，运行时错误为 0：

1. 逐级展开，中间层不算选中；年假事项出现正确字段并校验全部必填项。
2. 日期、数字与空白文本校验；请假成功后显示完整路径与交接人，空表单再次点击不会新增记录。
3. 电脑申领的型号/数量字段、提交，以及切回请假后不残留旧值。
4. 报销金额、费用归属及多文件发票选择；记录显示文件名，成功后文件输入重置。
5. 公章用印文件、用途、份数等字段；不同事项间未提交的文件不会串入申请记录。
6. Escape 和外部点击关闭菜单。
7. HR 主管、部门负责人、普通员工均可使用新申请表单。
8. 6 层树通过连续方向键和 Enter 选中；不同深度的末级节点均可选择。
